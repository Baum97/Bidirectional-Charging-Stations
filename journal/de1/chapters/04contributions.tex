\subsection{Contributions}
\label{subsec:contributions}
This paper contributes a practical and reproducible workflow for planning bidirectional charging infrastructure with coupled traffic and grid evaluation. The approach is designed to support municipal planning and utility stakeholders with transparent trade-off analysis.

The main contributions of this work are as follows:
\begin{itemize}
	\item A simulation-based siting pipeline that jointly evaluates mobility accessibility and distribution-grid impact.
	\item A multi-criteria scoring framework for comparing candidate station portfolios under realistic demand variability.
	\item A reference implementation in Python to support reproducible experiments and scenario-based sensitivity studies.
\end{itemize}
